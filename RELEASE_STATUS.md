## What these artifacts establish

Muse SETUP adds a bounded installation scope that preserves its connector, authorization and stopped tasks and forbids global memory/other-skill changes. That new installation wording has not been re-run through native installation acceptance. Earlier failures remain separate facts.

Local package integrity, complete references and source alignment do not establish that every host installed or loaded every guide, that a model saw every image, or that all business cases passed. Host-native input provenance and context isolation remain incomplete. Muse may receive host-supplied context; the installation instructions are not a guarantee about host-wide memory behavior.

Dot attachment materialization can expose different bytes from the original attachment. Upload must stop on a supplied size/SHA mismatch, before phone control. This is an unresolved host-input boundary, not a proven browser-transcoding or server-upload defect.

Optional semantic UI observations are experimental and incomplete; inspect current images and actual outcomes. Evidence for semantics-disabled fallback concerns the new service, not all combinations of older binaries. Do not claim universal cancellation, recovery, all-app privacy, performance improvement or all-host workflow acceptance.

The permit-renewal scheduling defect has a completed targeted correction and separate regression. That result does not attribute every earlier session loss to the same cause or convert earlier business failures into passes.
